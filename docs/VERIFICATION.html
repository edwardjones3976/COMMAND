Verification steps that can actually run

This replaces the fifteen Verification steps of the working plan. Each step says who runs it. CI means the nightly-emulator workflow on API 36 and API 37 google_apis x86_64 emulators: RingSurfaceTest (instrumented) and scripts/reliability.sh (from outside the app). DC1 is the walked device checkpoint. A step listed for DC1 has not been run by anything here.

Not reachable by an emulator

A real phone ringing across reboots and days, phone makers' battery killers, headset routing, perceived loudness, NFC and QR hardware. The emulators run with no audio device, so "audio" above means the platform's list of active playback, not sound heard. API 37 hardening enforcement belongs to M17b.

Run one case locally: DEBUG_APK=... NOEXACT_APK=... scripts/reliability.sh kill. It erases the app's data on the attached device.
